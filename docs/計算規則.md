# 工作時程規劃器：日期計算規則

版本：v1（2026-10-19 確認）
程式實作：`js/scheduler.js`　測試：`tests/cases.js`

本文件是計算引擎的唯一依據。規則有改，先改這份文件和測試案例，再改程式。

---

## 一、基本定義

| 編號 | 規則 |
|---|---|
| R1 | 所有日期一律以 `YYYY-MM-DD` 字串處理，計算過程不經過 JavaScript 的 Date 時區轉換。 |
| R2 | **工作天**＝週一到週五且不在假日表「放假」名單；假日表標為「補班」的日期（即使是週六日）也算工作天。 |
| R3 | **非工作天**＝工作天以外的日子（週末、國定假日）。 |

## 二、單一工作的起訖

| 編號 | 規則 |
|---|---|
| R4 | **工作天任務 N 天**：開始日若是非工作天，順延到下一個工作天。開始當天算第 1 天，第 N 個工作天為結束日。 |
| R5 | **日曆天任務 N 天**：開始日不調整。結束日＝開始日＋N－1。**結束日若為非工作天，順延到下一個工作天**（期限遇假日順延）。 |
| R6 | **緩衝天數**：接在工作天數之後，單位與該工作相同。計算時視為工作天數＋緩衝天數。 |
| R7 | **0 天＝里程碑**：日期為前置工作的結束日（不加一天）。沒有前置工作則為專案開工日。工作天類型的里程碑若落在非工作天，順延到下一個工作天。 |

## 三、工作之間的銜接

| 編號 | 規則 |
|---|---|
| R8 | 後續工作從前置工作結束的**隔天**起算，再依 R4／R5 決定是否順延。 |
| R9 | 有多項前置工作時，取最晚可以接手的那一項。 |
| R10 | **間隔天數**：前置工作結束後再空出 N 天。單位跟著**後續工作**的類型（工作天類型空 N 個工作天，日曆天類型空 N 個日曆天）。 |
| R11 | 沒有前置工作的，從**專案開工日**起算。 |
| R12 | **指定最早開始日**（選填）：工作不得早於這一天開始。 |

## 四、實際進度與「今天」

| 編號 | 規則 |
|---|---|
| R13 | 填了**實際開始日**：開始日以實際日期為準，不受前置工作、指定日期或今天影響。 |
| R14 | 填了**實際完成日**：結束日以實際日期為準。後續工作全部依此重算，提早就提前、延誤就順延。 |
| R15 | **尚未開始**（沒有實際開始日）的工作，開始日不得早於今天：算出來的開始日已經過去的話，改從今天起算，後面全部順延。指定最早開始日已經過去時也一樣。 |
| R16 | **進行中**（有實際開始日、沒有實際完成日）的工作，結束日不得早於今天：預計結束日已經過去的話，結束日改為今天（今天若是非工作天，順延到下一個工作天）。 |
| R17 | 里程碑只看實際完成日。填了就以它為準；沒填就適用 R15。 |
| R18 | 「今天」是計算時傳入的參數，測試可以固定任意日期。 |

## 五、發售日、專案完成日、關鍵路徑

| 編號 | 規則 |
|---|---|
| R19 | **專案完成日**＝所有工作中最晚的結束日。 |
| R20 | 每個專案可把一項工作標為「發售」。**發售日**＝該工作的開始日。沒有標記時，發售日＝專案完成日。 |
| R21 | **關鍵路徑**：從發售工作（沒標記則為最晚結束的工作）往回追。每一步選出「決定這項工作開始日的前置工作」，若有多項同時決定，全部列入。開始日若是由開工日、指定日期、今天或實際日期決定，追到這裡為止。 |

## 六、錯誤與警告

| 編號 | 規則 |
|---|---|
| R22 | **錯誤**（停止計算）：循環依賴、依賴自己、依賴不存在的工作、天數為負數或非整數、日期格式錯誤、實際完成日早於實際開始日。 |
| R23 | **警告**（照常計算）：計算涉及的年份沒有假日資料。 |

## 附錄：每項工作的計算說明代碼

計算結果會附上開始日、結束日的決定原因，給畫面顯示「為什麼是這天」。

| 開始日原因 | 意思 |
|---|---|
| `project_start` | 專案開工日 |
| `dependency` | 等前置工作（附上是哪幾項） |
| `earliest_start` | 指定最早開始日 |
| `today` | 原定日期已過、尚未開始，改從今天起算 |
| `actual` | 實際開始日 |

| 結束日原因 | 意思 |
|---|---|
| `calculated` | 依天數計算 |
| `today` | 進行中且已逾期，推到今天 |
| `actual` | 實際完成日 |

另有 `startShifted`、`endShifted` 標記，表示日期因遇到非工作天而順延。
